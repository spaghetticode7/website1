# Maria Livadina - Personal Website

A professional website showcasing Maria Livadina's career as an opera singer and performer.

## About

This website features Maria Livadina's professional profile, including her education, training, and extensive performance experience in theatre and opera. Maria is an accomplished Opernsängerin (opera singer) and Mezzosopranistin with performances across Moscow, Turkey, and Germany.

## Features

- **Professional CV Display** - Full curriculum vitae integrated directly into the website
- **Performance History** - Comprehensive list of theatrical and operatic performances
- **Education & Training** - Detailed information about her training at prestigious institutions
- **Responsive Design** - Optimized for mobile and desktop viewing
- **Professional Navigation** - Easy-to-use navigation between sections

## Getting Started

### Installation

1. Clone the repository:
```bash
git clone https://github.com/spaghetticode7/website1.git
cd website1
```

### Running the Project

To start a local development server:
```bash
python -m http.server 3000
# or
npm start
```

The website will be available at `http://localhost:3000`
